Lezione Box Sizing Css

content-box (default)

Utilizzando invece il tag content-box si stadicendo che le dimensioni che io dò al mio tag devono valere solo per il mio contenuto

Contenuto del box. Dimensione finale: 280px x 180px

border-box

Con Border box noi stiamo dicendo che le dimensioni che noi stiamo dando al nostro tag devono rientrare dal margine al Contenuto

Quindi se io metto width del mio div 200px (lui si adatterà in automatic a parte casi estremi per poter avere un blocco unico da 200px di larghezza)

Contenuto del box. Dimensione finale: 280px x 180px

Spiegazione

Il primo box ha dimensioni finali di 280x180px perchè:

  1. Width: 200px+30px padding sx + 30 px padding dx + 10 px di border sx + 10px border dx = 280px
  2. Height: 100px+ 30px padding top+ 30px padding bottom + 10px border top + 10px border bottom = 180px
  3. Il margin (50px) crea spazio attorno ma non aumenta le dimensioni del contenitore
